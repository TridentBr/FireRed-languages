# FireRed Languages — Development Prototype

AI-assisted experimental prototype. Use at your own risk and back up saves.

This package contains a **non-invasive Gen1Recomp API smoke test**, not a full translation. All repository documentation and code comments are in English; player-facing strings are in their target language.

Upload `mod/firered_languages_ptbr/` into the repository's `develop` branch. Do not merge to `main` or tag a stable release before upstream validation and Android testing.

See `mod/firered_languages_ptbr/README.md` for validation commands.

Upstream: https://github.com/bryanthaboi/gen1recomp
