# Android testing guide

1. Back up save files and settings before installing a mod.
2. Record the exact Gen1Recomp build and FireRed version.
3. Install only a build explicitly marked as experimental.
4. Confirm the game launches and the language menu appears.
5. Switch languages, restart the app, and verify the selected language persists.
6. Confirm the saved game remains accessible and unmodified.
7. Record screenshots, reproduction steps, and logs for any failures.

**This repository starter package does not contain a validated playable mod.**
